# SMOG3 Repository Split Plan

This branch can be merged into the current SMOG2 repository or used as the
source for a standalone GitHub repository named `smog3`.  The recommended first
standalone pass is documentation and packaging cleanup only; move legacy files
after validation scripts have been adjusted and rerun.

## Recommended Standalone Layout

```text
smog3/
  pyproject.toml
  README.md
  CHANGELOG.md
  COPYING
  CITATION.cff
  src/smog3/
  tests/
  scripts/
  docs/
  examples/
  validation/
  notebooks/
```

## Keep In `smog3`

- `pyproject.toml`
- `README.md`
- `CHANGELOG.md`
- `COPYING`
- `CITATION.cff`
- `src/smog3/`
- `tests/`
- `scripts/`
- `docs/`
- `examples/basic_aa/`
- `examples/basic_ca/`
- `examples/opensmog/`
- `examples/compare_with_smog2/`
- `validation/tutorials/tutorial_manifest.yml`
- `validation/tutorials/assets/manifest_raw.json`

These files are needed for the Python package, documentation, examples,
release checks, or reproducible validation.

## Validation-Only

- `SMOG-CHECK/`
- `validation/smogcheck/`
- `scripts/run_selected_two_stage_parity.sh`
- `scripts/run_all_smogcheck_two_stage_parity.sh`
- `scripts/run_smogcheck_dropin_smog3.sh`
- `scripts/run_all_tutorials_compare.sh`
- `scripts/fetch_smog_tutorial_assets.py`
- `scripts/validate_real_pdb_panel.sh`

These are not required for normal installed `smog3` runtime.  They are retained
so contributors can compare SMOG3 outputs against official SMOG2 Docker
baselines and the original SMOG-CHECK harness.

## Move To `legacy_smog2/` Or Separate Archive

- `src/smogv2`
- legacy Perl tools under `src/tools/` other than validation references
- root-level historical SMOG2 support files not consumed by SMOG3 package data
- old GROMACS example outputs under `examples/gromacs*/`
- `share/` legacy template/data layout if no script still reads it directly
- `bin/`, `lib/`, or installer files that exist only for legacy SMOG2

Before moving any of these, update path assumptions in validation scripts and
rerun:

```bash
PYTHONPATH=src pytest -q tests
bash scripts/run_selected_two_stage_parity.sh
bash scripts/run_smogcheck_dropin_smog3.sh 1 115
bash scripts/run_all_tutorials_compare.sh --all
```

## Generated Or Ignored

- `parity_runs/`
- `smogcheck_dropin_runs/`
- `validation/tutorials/runs/`
- `validation/tutorials/assets/downloads/`
- `validation/tutorials/assets/pages/`
- `real_pdb_validation/`
- `installed_smog3_verify/`
- `dist/`
- `build/`
- `*.egg-info/`
- `parity_case1.json`
- `parity_selected.json`
- `parity_all_summary.json`
- root-level `model.top`, `model.gro`, `model.ndx`, `model.contacts`,
  `model.xml`, and backup variants
- `table.xvg`

Do not commit these outputs.  They should be regenerated by scripts when needed.

## Remove

- ad hoc local helper scripts that are not documented or used by tests.
- temporary downloaded PDBs or model outputs created during manual validation.

## Recommendation

For merge into the current repository, keep the existing layout because it is
fully validated.  For a new standalone `smog3` repository, start by copying the
`keep` and `validation-only` groups, preserving `SMOG-CHECK/` until equivalent
validation fixtures are relocated.  Move legacy SMOG2 files only in a follow-up
branch after the validation scripts no longer depend on historical paths.
